
# 01. Declaración de alcance – ZYRA PALLET

## Descripción del proyecto

ZYRA PALLET es una aplicación móvil desarrollada con Flutter
para gestionar y controlar pallets dentro de un entorno logístico.

Permite registrar pallets, consultar información, buscar por
código y visualizar movimientos.

## Módulos y servicios

| Módulo / servicio | ¿Aplica? | Observación |
|---|---|---|
| Autenticación | Sí, pendiente | Se integrará Firebase Authentication |
| Base de datos | Sí | Supabase |
| Almacenamiento | Pendiente | Se evaluará Firebase Storage |
| Notificaciones push | Pendiente | Firebase Cloud Messaging |
| API REST externa | No | No implementada actualmente |
| Otros | No | Sin otros servicios declarados |
